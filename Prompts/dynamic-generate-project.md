# STS2モッドの動的生成機能にアップグレード

## 現状
既にSTS2Mod用テンプレートプロジェクト&ビルド済みを用意

## ゴール
画面からの設定値(今はキャラクター名のみ)を元に
プロジェクト生成し、ビルドorそのままでプロジェクトをダウンロード可能

生成完了後当ファイルに生成内容を追記

## 実装内容（2026-11-24）
- 画面のキャラクター名から、ソース版の Mod ID、フォルダー名、`.csproj`・Mod設定ファイル名、C# 名前空間と表示名を生成する。
- ソース版は生成した C# プロジェクトを ZIP でダウンロードできる。ビルド済み版は共通 DLL を使い、入力名を `character.json` と Mod設定ファイルに反映した ZIP をダウンロードできる。
- 両形式の ZIP に `GENERATION.md` を追加し、生成名・形式・Mod ID・フォルダーを記録する。
- このページは GitHub Pages の静的アプリのため、ブラウザー上で C# のビルドは実行しない。ソース版は同梱の README の手順でビルドする。
- `node --test tests/generator.test.cjs` でソース構成、特殊文字、ビルド済み DLL の保持を確認する。
